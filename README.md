# DeVowel

**Exploring Vowel-Reduced Vocal Timbre**

DeVowel is an experimental audio DSP project exploring whether vowel identity can be reduced in a sustained human voice while preserving speaker-specific vocal characteristics.

## Core Question

Can vowel identity be reduced while preserving the characteristic timbre of the original voice?

## Project Direction

The project will explore:

- spectral envelope and formant analysis
- vowel reduction and source-filter separation
- resynthesis with new vowel formants
- artificial non-vowel resonance structures for vocal instrument design

## Status

Early development — first prototype in progress.
